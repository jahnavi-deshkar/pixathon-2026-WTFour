# Prism Heist — Top-Down Stealth Laser-Routing Puzzle

A complete, zero-build-step HTML5 Canvas stealth laser puzzle game ready for instant deployment on **Vercel**.

DEMO LINK: https://prism-heist.vercel.app/

## 📂 Customizing Sprites & Audio (`/assets`)

All starter sprites (`64x64` PNG) and synthesized sound effects (`.wav`) are pre-populated in `assets/sprites/` and `assets/audio/`:

### `assets/sprites/` (64×64 PNG, transparent background)
- `emitter.png` — Laser emitter torch (pointing East/Right by default)
- `diamond.png` — Target diamond enclosed in glass vault
- `mirror_slash.png` — Reflective mirror `/` (45°)
- `mirror_backslash.png` — Reflective mirror `\` (135°)
- `sensor.png` — Red static light/motion photo-sensor
- `cctv.png` — Rotating security CCTV camera turret
- `booster.png` — Violet range amplifier prism crystal
- `wall.png` — Museum solid pillar block
- `floor.png` — Museum floor grid tile
- `title_banner.jpg` — 16:9 Main Menu hero illustration

### `assets/audio/` (.wav or .mp3)
- `bgm_heist.wav` — Looping espionage synth bass/pad
- `sfx_place.wav` — Mirror placement click
- `sfx_rotate.wav` — Mirror rotation servo blip
- `sfx_laser.wav` — High-powered laser beam fire hum
- `sfx_win.wav` — Vault diamond illuminated jingle
- `sfx_alarm.wav` — Security breach / sensor alarm siren
- `sfx_tick.wav` — Final 10-second execution countdown tick
